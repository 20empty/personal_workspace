# 代码审查

对当前变更进行全面、专业代码审查。

!`git diff --name-only main...HEAD`

## Detailed Diff

!`git diff main...HEAD`

审查重点包括：
- 功能正确性：是否有逻辑错误、边界情况未处理？
- 代码质量：可读性、命名规范、重复代码、复杂性过高？
- 安全性：潜在漏洞、输入验证、权限问题？
- 性能：低效查询、内存泄漏、不必要的计算？
- 测试覆盖：是否需要补充测试？
- 最佳实践：是否符合项目编码规范、架构原则？

对于每个发现的问题：
- 给出具体文件:行号
- 说明问题严重程度（🔴 必须修复 / 🟡 建议 / 🟢 优化）
- 提供改进建议或修复代码片段

最后给出整体总结：是否可以合并？主要风险是什么？
