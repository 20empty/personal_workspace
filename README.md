# Classroom

Classroom is an offline-first desktop workspace for delivery-focused trainers. It brings together class delivery progress, client and learner management, and personal dev task tracking in a fast, local-only app.

## Stack
- Tauri v2 + React 18 + Vite
- TypeScript + Tailwind CSS + shadcn/ui
- Framer Motion
- SQLite + Drizzle ORM (planned)

## Modules
- Dashboard: delivery progress, today’s teaching tasks, recent dev activity
- Delivery Manager: enterprise clients, cohorts, attendance, lab completion
- Dev Tracker: Kanban/task list for scripts, maintenance, and course R&D

## Development
```bash
npm install
npm run dev
```
